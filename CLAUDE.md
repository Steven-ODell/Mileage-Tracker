# mileage-log

Android-only Expo app (SDK 57, RN 0.86, TypeScript): IRS-style mileage log for
Sao's 1099 roofing field work. Spec and milestones were given in chat on
2026-09-21; milestone 1 (installable build with a Start day button) is done.

- Build: `./scripts/build-apk.sh` → `build/mileage-log.apk` (release, debug-signed).
- `android/` is generated by `expo prebuild`; config lives in `app.json`. Never hand-edit `android/`.
- JDK comes from `.mise.toml`; SDK is `~/Android/Sdk`. AVD `mileage` lives in
  `~/.config/.android/avd`, so set `ANDROID_AVD_HOME` when launching the emulator.
- Kill the emulator when done (`adb emu kill`).
